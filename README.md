# GPS Damga privacy and support site

Public privacy policy, terms and support pages for GPS Damga by Albatros Development.

- Turkish privacy policy: index.html
- English privacy policy: en.html
- Terms of use: terms.html
- Support: support.html

The site describes the current ad-supported release candidate and its support
for an optional monthly auto-renewing Ad-free Use subscription through Google Play. The
advertising scope is one bottom banner only in the content-populated main
gallery, folder list and real project list; all other screens and blocking UI
states remain ad-free. Keep the policy, Google Play Data safety declaration,
subscription terms and app link aligned with every SDK or data-handling change.
